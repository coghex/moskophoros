**Disposition:** documentation drift (low priority).
**Verification:** verified at the pin, including an executable manifest probe.
**Principle:** V-2; #157 requirement 6, #159's public schema transition and #160 requirement 7; AGENTS.md's current-behavior documentation rule.

**Evidence:** [design §Reuse, lines 1394–1396](https://github.com/coghex/moskophoros/blob/36e4e3e8f0e4739cf26afef35f2ed0b7b5286d72/docs/design.md#L1394-L1396) still says, “The rest of the sheet is not checked beyond its `schema`”. The earlier paragraph at [lines 1202–1216](https://github.com/coghex/moskophoros/blob/36e4e3e8f0e4739cf26afef35f2ed0b7b5286d72/docs/design.md#L1202-L1216) correctly requires whole-manifest validation. [manifest.decode](https://github.com/coghex/moskophoros/blob/36e4e3e8f0e4739cf26afef35f2ed0b7b5286d72/src/moskophoros/manifest.py#L453-L481) implements the strict rule through structure and derived-record checks. Removing `frames` from a valid manifest gives exit 2, `probe.json: frames: missing`; changing `source.sha256` without resealing the fingerprint also gives exit 2. Neither field is inside `settings`.

Two related preparatory descriptions also survived public activation: [lighting.py:9–11](https://github.com/coghex/moskophoros/blob/36e4e3e8f0e4739cf26afef35f2ed0b7b5286d72/src/moskophoros/lighting.py#L9-L11) says it is “wired to no command yet”, and [dither.py:10–13](https://github.com/coghex/moskophoros/blob/36e4e3e8f0e4739cf26afef35f2ed0b7b5286d72/src/moskophoros/dither.py#L10-L13) says the same. The command supplies responses and lights to stylize, which calls these kernels through `shade_layers`.

**Consequence:** a reader following the old reuse sentence can reasonably expect a settings-only or externally edited manifest to load and instead receives a usage error. Maintainers can also mistake the active shading kernels for unfinished foundations. Runtime validation is correct; this is not a data-loss, rendering or replay defect.

**Action:** remove or replace the obsolete reuse sentence and update the two module descriptions to state that the command uses them through stylize. Keep the strict reader and its existing tests. This is one small code-lane correction because tests read `docs/design.md`; the module docstrings are code-lane files too. No new runtime behavior or textual mirror tests are warranted. Exact tracker/disposition proposal awaits this item's turn.

**Dedup:** #110 fixed earlier descriptions before these later transitions; #157/#159/#160 are closed deliveries, not open follow-ups for this residual text.
