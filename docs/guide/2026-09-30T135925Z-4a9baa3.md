## What moved

- **#13 / #12:** makes the local-only Blender group nonempty. Discovery
  preserves an explicit override, resolves relative executables before changing
  directories, and fails instead of skipping. The process requires both exit 0
  and a success line after importing `bpy` in background mode. The supported
  version check remains deliberately deferred to the capture backend.
- **#19 / #14:** starts the aggregate independently, waits on terminal jobs
  from its own run attempt, and rejects missing or unsuccessful jobs and
  mismatched records. Existing cancellation evidence shows cancelled aggregate
  checks, answering the first report's skipped-check suspicion for those runs.
- **#20 / #15:** retains the descriptor-versus-tree fingerprint check and
  confirms the descriptor's exact digest and recorded versions before any
  group receives an image. Failed confirmation stops groups and reaches the
  aggregate's diagnostic.
- **#21 / #16:** prefixes all group jobs with `group/`, reserves required
  check IDs in shared catalog validation, and updates the aggregate's waits.
  Requests, local reports and records retain their catalog IDs.
- **#22 / #17:** stages committed blobs directly, with the committed
  executable bit, and rejects nonregular entries before writing. Its new
  fingerprint has a matching published image and committed descriptor;
  #20's identity check still protects the resulting execution.
- **#23 / #18:** asserts a divergent merge-base history and literal reason
  text; safely displays non-UTF-8 paths, separators and control characters.
  Plans loaded from JSON remain safe when CI renders their summaries, while
  matching and the JSON path values remain unchanged.
- **Plan:** reviewed all six new effective issue specifications, including
  every review amendment. Each is closed and implemented by its linked merge.
  Epic #3 and earlier issue fingerprints are unchanged, so their previous
  specification coverage is inherited. No open pull requests were captured.

The two standalone documentation landings in the delta are excluded review
targets. They contribute no defect or alignment verdict.
